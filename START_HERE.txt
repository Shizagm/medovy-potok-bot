МЕДОВЫЙ ПОТОК — Windows, версия 0.9

Обновляете существующего бота? Сначала UPGRADE.txt.
Новые функции Роя и лавки: ROY_AND_SHOP.md.
Визуальный пример меню: DESIGN_PREVIEW.html.

1. Распакуйте ВЕСЬ архив в постоянную папку, например C:\MedovyPotok.
   Не запускайте файлы прямо из ZIP. Не храните рабочую базу в синхронизируемой
   папке OneDrive: для резервирования копируйте готовые резервные копии отдельно.
2. Установите обычный Python 3.11 или новее с python.org, если его ещё нет.
   Для классического установщика включите Add Python to PATH.
   В PowerShell проверьте: py -3 --version
3. В Telegram нажмите «Запустить» у бота, добавьте его в закрытую группу
   администратором и отправьте там /id@username_бота.
4. Дважды нажмите CONFIGURE.bat. Вставьте токен (ввод скрыт), выберите свой
   числовой ID и ID группы. Проверьте показанное название группы и сохраните.
   Не присылайте .env и токен другим людям.
5. Дважды нажмите START_BOT.bat. После «Рой готов» проверьте /start и /admin
   в личной переписке с ботом.
6. Не закрывайте окно и отключите автоматический сон компьютера на время работы.
   При выключении компьютера бот останавливается; при запуске снова считает
   прошедшие дни постоя. Для остановки нажмите Ctrl+C, дождитесь завершения.

В группе боту нужно право управления тегами участников. Если право недоступно,
Вдохновение всё равно хранится в /profile, но подпись возле имени не обновится.
PUBLIC_TOPIC_ID можно пока оставить 0: сообщения идут в общий раздел группы.

Сайт остаётся на Спринтхосте. Открывать порты и настраивать роутер не нужно.
Токен тот же, новый бот не требуется. Не запускайте его одновременно на сервере
и на компьютере. Данные хранятся в data. Если сервер уже содержал реальную БД,
сначала остановите его и перенесите резервную копию вместе с данными.

Все игровые команды и правила — в README.md. Отдельные Linux-инструкции из
README для Windows не нужны. Docker, tmux и SSH для локального запуска не нужны.

Проверено: игровые автотесты, POSIX-блокировка, имитация Windows API блокировки,
резервный часовой пояс и сохранение настройки UTF-8. На настоящей Windows
и с вашим Telegram-токеном эта сборка ещё не запускалась.
